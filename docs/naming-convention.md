## Naming Convention Pattern
Convention for Northwind Services company. This document will encompasses the naming, groupings, and summary reasoning behind them.

# Convention
- <Company_Name> - <Location_> - <Department/Role>
  - Ex. NWS - ATL - Security
  - Ex. NWS - FL - Finance
  - Ex. NWS - DC - HelpDesk
  
# Company_name
- Company name is 'Northwind Services'. Shortened version will be 'NWS' to allow current and future groups/policies to align.

# Location
- Location is currently only based in ATL. However, planning for future expansion and scaling is best done at beginning.

# Department/Role
- Department and role can both align as Helpdesk is a role, however finance is a department. There is no need to add another layer as specific role will apply to whole organization.


**This current naming convention is optimal for current organization use cases as well as future. It presents a foundation for future growth based on scale.**
